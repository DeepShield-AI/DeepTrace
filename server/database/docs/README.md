# Database Tables Introduction

The database currently contains the following five tables:

- agent_list: Stores agent configuration information
- agent_status: Agent will periodically send its status information to this table after it starts running
- spans_agent_*: Stores spans generated by each agent
- span-mappings: After the association algorithm is executed, each span will be assigned a parentid
- traces: Assembled trace collection

## agent_status

Each row corresponds to the status of an agent, in the following format:

```json
{
  "name": "agent1",
  "state": "running",
  "timestamp": "22:27:01.919489486"
}
```

## spans_agent_*

Each row corresponds to a span, in the following format:

```json
{
  "component": "ComposePostServ",
  "direction": "Egress",
  "dst_ip": 2886991891,
  "dst_port": 43144,
  "end_time": 1309219224692769,
  "pid": 3498777,
  "protocol": "Thrift",
  "req_content": "***",
  "req_seq": 0,
  "resp_content": "*****",
  "resp_seq": 1,
  "src_ip": 2886991898,
  "src_port": 9090,
  "start_time": 1309219224414818,
  "tgid": 3008178
}
```

## span-mappings

Each row corresponds to a span, which is assigned a parentid based on the original span.

## traces

```json
{
  "trace_id": "929e1e0ad8b166d8",
  "span_num": 20,
  "e2e_duration": 7750846,
  "endpoint": "ComposePost",
  "component_name": null,
  "server_ip": "172.20.0.19",
  "server_port": 9090,
  "client_ip": "172.20.0.17",
  "client_port": 52678,
  "protocol": "Thrift",
  "status_code": null,
  "spans": [{span1}, {span2}]
}
```
